Study Mate AI

Your Smart Learning Companion

Java Swing Desktop Application | Java + MySQL

Project Overview

Study Mate AI is a Java-based desktop application developed to help students manage their learning activities. It provides separate login facilities for administrators and students. The application uses Java Swing for the graphical user interface and MySQL for database management.

Technologies Used

- Java (JDK 21)
- Java Swing
- JDBC
- MySQL
- Apache Maven
- NetBeans IDE

Project Modules

Admin Modules

- Admin Login
- Student Management
- Subject Management
- Study Notes Management
- Task Assignment
- Quiz Results
- AI Study Assistant

Student Modules

- Student Login
- Student Dashboard
- View Subjects
- View Study Notes
- View and Submit Tasks
- Attend Quiz
- View Quiz Results

Key Features

- Separate admin and student login.
- Manage student and subject information.
- Create and view study notes.
- Assign tasks and submit task answers.
- Attend quizzes and view scores.
- AI Study Assistant provides basic keyword-based learning responses.
- MySQL database integration for storing and retrieving information.

Database

The project uses MySQL to store application data, including students, subjects, notes, tasks, administrators, and quiz results.

Conclusion

Study Mate AI is designed to make student learning activities easier through a simple desktop interface. It combines Java Swing and MySQL to provide learning management features in one application.
